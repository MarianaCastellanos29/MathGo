\# Módulo de Autenticación - MathGO Este módulo gestiona el login, registro y control de sesión de los usuarios (alumnos y padres). ## Componentes involucrados - AuthService: maneja login, registro, logout y datos de sesion (token, usuario, rol) - AuthGuard: protege rutas que requieren sesion iniciada - AuthInterceptor: agrega el token a las peticiones HTTP automaticamente ## Flujo de registro 1. El usuario completa nombre, correo, contrasena y rol (alumno o padre) 2. Se envia al backend mediante AuthService.registrar() 3. Si es exitoso, redirige al login ## Flujo de login 1. El usuario ingresa correo y contrasena 2. AuthService.login() valida contra el backend y guarda el token en localStorage 3. AuthGuard permite el acceso a rutas protegidas usando ese token
